Understanding the Normal Equation

Linear regression is one of the most fundamental models in machine learning. In fact, least squares linear regression, commonly called “ordinary least squares” or “OLS”, was first discovered by Isaac Newton over 250 years before the term “machine learning” was coined!1

Linear Regression

Linear regression works by fitting a high-dimensional “plane” to a dataset. This is easiest to visualize in the case where our features (inputs) are one-dimensional:

Code 
from sklearn.datasets import make_regression
import numpy as np

X, y = make_regression(n_samples = 50, n_features= 1, n_informative=1, n_targets=1, bias=2, noise = 10, random_state=42)

# Doing regression

## add bias term
X_b = np.hstack((np.ones(X.shape), X))
## use the normal equation to find the best fit

theta = np.linalg.solve((X_b.T @ X_b), (X_b.T @ y))

X_line = np.linspace(X.min(), X.max(), 100)
y_line = X_line * theta[1] + theta[0]


## plot results
import plotly.graph_objects as go

fig = go.Figure()
fig.add_trace(go.Scatter(x=X.flatten(), y=y, mode='markers', name='random data'))
fig.add_trace(go.Scatter(x=X_line, y=y_line, mode='lines', name='best fitting line'))

fig.update_layout(
    title=dict(text="Simple 2-D Linear Regression", x=0.5, xanchor="center"),
    yaxis=dict(showticklabels=False),
    margin=dict(l=20, r=20)
)
fig.show()

We can also visualize regression in three dimensions (so, two dimensions for features, since the third is the value we are trying to predict).

Code 
X, y = make_regression(n_samples = 100, n_features= 2, n_informative=2, n_targets=1, bias=2, noise = 30, random_state=42)

# Doing regression

## add bias term
X_b = np.hstack((np.ones((X.shape[0], 1)), X))
## use the normal equation to find the best fit

theta = np.linalg.solve((X_b.T @ X_b), (X_b.T @ y))


ax_1 = np.linspace(X[:, 0].min(), X[:, 0].max(), 100)
ax_2 = np.linspace(X[:, 1].min(), X[:, 1].max(), 100)
X_plane = np.array(np.meshgrid(ax_1, ax_2, indexing='xy'))

y_plane = theta[0] + theta[1] * X_plane[0] + theta[2] * X_plane[1]


## plot results
fig = go.Figure()
fig.add_trace(go.Scatter3d(x=X[:, 0], y=X[:, 1], z=y, mode='markers', name='random data',
    marker=dict(size=5)))
fig.add_trace(go.Surface(x=ax_1, y=ax_2, z=y_plane, opacity=0.5, showlegend=False, showscale=False))
fig.update_layout(
    title=dict(text="Simple 3-D Linear Regression", x=0.5, xanchor="center"),
    margin=dict(t=40, b=40, l=0, r=0),
    scene=dict(
        zaxis=dict(showticklabels=False, title="", showline=False, zeroline=False),
        camera=dict(
            eye=dict(x=0.9, y=-2.0, z=1.4),
            center=dict(x=0, y=0, z=-0.15)
        )
    )
)
fig.show()

In this example, we define the “line (or plane) of best fit” as the one which minimizes the mean of the squared distance between our prediction and the data at all points. This is called “mean squared error” or “MSE”. MSE is calculated as \mathrm{MSE} = \frac{1}{n} \sum_{i = 1}^{n} (y_i - \hat{y}_i)^2,

where y_i is the true value of the i-th sample of our dataset, and \hat{y}_i is our prediction of the true value using only the i-th set of features x_i.

Usually, we find the parameters x describing the line of best fit through some form of gradient descent. But in cases where our dataset is small enough, we can use a closed form solution to find the optimal parameters. This closed form solution looks like solving the linear equation

A^T A x = A^T y.

This equation is called the normal equation, and the rest of this blog is devoted to understanding why it works!

The Normal Equation

We can represent our plane of best fit as a linear equation:

Ax = \hat{y},

where A is an n by d matrix (n are the number of data points we have, d represents the number of features our dataset has), x is a vector representing our parameters, and \hat{y} is our prediction. Our goal is to find the x which minimizes the MSE between our predictions and our true labels. Let’s rewrite MSE:

\mathrm{MSE} = \frac{1}{n} \sum_{i = 1}^{n} (y_i - \hat{y}_i)^2 = \frac{1}{n} \|A x - y\|^2 = \frac{1}{n} (A x - y)^T (A x - y).

Since \frac{1}{n} is a positive constant, we can ignore it when trying to finding the minimum of or error term: the minimizing input of a function f is the same as the minimizing input of cf where c is positive.

So the parameters x which minimize the MSE also minimize f(x) = (A x - y)^T (A x - y).

f(x) = (A x - y)^T (A x - y) = x^T A^T A x - x^T A^T y - y^T A x + y^T y.

The minimum of this function occurs when the gradient is zero (this is because MSE with linear regression is convex, a blog post about convexity and why it is important is soon to follow!). Taking the gradient of f with respect to x yields

\nabla f(x) = \nabla \left(x^T A^T A x\right) - \nabla \left(x^T A^T y\right) - \nabla \left(y^T A x\right).

Notice that y^T y is dropped since it doesn’t depend on x: the derivatives of constants are always 0.

Evaluating Gradients

Now we need to evaluate \nabla \left(x^T A^T A x\right), \nabla \left(x^T A^T y\right), and \nabla \left(y^T A x\right). A lot of tedious math is to follow. If that doesn’t interest you, feel free to skip here.

Evaluating \nabla \left(x^T A^T A x\right)

Starting with \nabla \left(x^T A^T A x\right). Let S = A^T A. Since A is n \times d, S is d \times d. S is also symmetric, which will help us later: \begin{aligned} S_{ij} & = (A^T A)_{ij} = A^T_{i \cdot} \cdot A_{\cdot j} = \sum_{k = 1}^{n} (A^T)_{ik} A_{kj} = \sum_{k = 1}^{n} A_{ki} A_{kj} \\ &= A_{\cdot i} \cdot A_{\cdot j} = A_{\cdot j} \cdot A_{\cdot i} \\ &= \sum_{k = 1}^{n} A_{kj} A_{ki} = A^T_{j \cdot} \cdot A_{\cdot i} = (A^T A)_{ji} = S_{ji}. \end{aligned}

So x^T A^T A x = x^T S x, which we can write as

x^T S x = x^T \begin{bmatrix} \sum_{i = 1}^{d} S_{1i} x_i \\ \sum_{i = 1}^{d} S_{2i} x_i \\ \vdots \\ \sum_{i = 1}^{d} S_{di} x_i \end{bmatrix} = x_1 \sum_{i = 1}^{d} S_{1i} x_i + x_2 \sum_{i = 1}^{d} S_{2i} x_i + \cdots + x_d \sum_{i = 1}^{d} S_{di} x_i.

Let’s consider the partial derivative of the above with respect to x_k: \begin{aligned} \frac{\partial}{\partial x_k} x^T S x &= \frac{\partial}{\partial x_k} \left( x_1 \sum_{i=1}^{d} S_{1i} x_i + x_2 \sum_{i=1}^{d} S_{2i} x_i + \cdots + x_d \sum_{i=1}^{d} S_{di} x_i \right) \\ &= x_1 S_{1k} + x_2 S_{2k} + \cdots + \sum_{i=1}^{d} S_{ki} x_i + x_k S_{kk} + \cdots + x_d S_{dk}. \end{aligned}

Remembering that S is symmetric means that S_{ki} = S_{ik}, so

\begin{aligned} \frac{\partial}{\partial x_k} x^T S x &= x_1 S_{1k} + x_2 S_{2k} + \cdots + \sum_{i=1}^{d} S_{ki} x_i + x_k S_{kk} + \cdots + x_d S_{dk} \\ &= S_{k1} x_1 + S_{k2} x_2 + \cdots + S_{kd} x_d + \sum_{i=1}^{d} S_{ki} x_i \\ &= 2 \sum_{i=1}^{d} S_{ki} x_i \\ &= 2 S_{k \cdot} \cdot x. \end{aligned}

Since \nabla g(x) = \begin{pmatrix} \frac{\partial}{\partial x_1} g(x) \\ \frac{\partial}{\partial x_2} g(x) \\ \vdots \\ \frac{\partial}{\partial x_d} g(x) \end{pmatrix}, we can write \begin{aligned} \nabla \left(x^T A^T A x\right) &= \begin{pmatrix} 2 S_{1 \cdot} \cdot x \\ 2 S_{2 \cdot} \cdot x \\ \vdots \\ 2 S_{d \cdot} \cdot x \end{pmatrix} = 2 S x \\ &= 2 A^T A x \end{aligned}

Evaluating \nabla \left(x^T A^T y\right)

Since A^T y is a vector, we can write x^T A^T y as a dot product:

x^T A^T y = \sum_{i=1}^{d} x_i (A^T y)_i.

So when we take the partial derivative with respect to x_k, all terms vanish except the k-th one, so

\frac{\partial}{\partial x_k} x^T A^T y = (A^T y)_k,

which we stack into

\nabla \left(x^T A^T y\right) = A^T y.

Evaluating \nabla \left(y^T A x\right)

Similar to what we did above, we can consider \left(y^T A x\right) as a dot product between the row vector y^T A and the column vector x. Doing this yeilds

y^T A x = (y^T A) x = \sum_{i=1}^{d} (y^T A)_i \, x_i.

And just like what happens above, the partial derivative with respect to x_k causes all terms except the k-th to vanish, so

\frac{\partial}{\partial x_k} y^T A x = (y^T A)_k,

and we can stack these partials so that

\nabla \left(y^T A x\right) = \begin{bmatrix} (y^T A)_1 \\ (y^T A)_2 \\ \vdots \\ (y^T A)_d \end{bmatrix} = (y^T A)^T = A^T y.

Notice that we have to transpose (y^T A) since it is a row vector.

Combining Evaluated Gradients

Now that the algebra is over, we can combine the gradents we computed into

\begin{aligned} \nabla f(x) &= \nabla \left(x^T A^T A x\right) - \nabla \left(x^T A^T y\right) - \nabla \left(y^T A x\right) \\ &= 2 A^T A x - 2 A^T y \end{aligned}.

We know f(x) will be minimized when it’s gradient is 0. So as promised, \nabla f(x) = 0 \implies A^T A x = A^T y.

This is very nice, but this equation only helps us if we know that it has a solution! We can intuit that this system is consistent (which means it has a solution) by considering that f(x) has to be positive everywhere, and shouldn’t asympoticaly approach an infimum along some sequence of parameter vectors whose norm approached infinity. But to be more rigourous, we can show the above system is consistent rigorously.

(P.S, A^T A x = A^T y is called the normal equation, providing the title for this section!)

Proving the Existence of a Solution

We want to show that the equation A^T A x = A^T y has a solution by proving that \col \left(A^T A\right) = \col \left(A^T\right) \tag{1} (\col B means column space, i.e. the set of vectors which can be produced by multiplying x \in \mathbb{R^d} with B). Proving equatioin 1 tell us since that A^T y \in \col \left(A^T\right) = \col \left( A^T A\right), there exists an x such that A^T A x = A^T y. We will prove equation 1 in two steps:

  1. showing \nul B^T B = \nul B
  2. showing \nul \left( B\right)^\perp = \col \left( B^T \right).

Proving Step 1

“\implies” Say x \in \nul B, then Bx = \vec{0} \implies B^T B x = 0, and therefore x \in \nul B^T B \implies \nul B \subset \nul B^t B.

“\impliedby” Say x \in \nul B^T B, then B^T B x = \vec{0} \implies x^T B^T B x = 0. But x^T B^T B x = \langle Bx, Bx \rangle = \|{Bx}\|2 = 0 \implies Bx = 0, which implies \nul B^T B \subset \nul B.

Combining these two proves that \nul B = \nul B^t B. \tag{2}

Proving Step 2

Showing step 2 will involve proving and inclusion then doing a dimentionality count.

First, let’s say x \in \col B^T and w \in \nul B. Then x = B^T y, and Bw = \vec{0}. Well, \langle w, x \rangle = w^T x = w^T B^T y = y^T B w = y^T \vec{0} = 0. So x is perpendicular to the nullity of B: x \in \nul \left(B \right)^\perp. This implies that \col B \subset \nul \left(B \right)^\perp. \tag{3}

Now, we use the dimension theorem and a property of the orthogonal compliment to show that \dim \col B =\dim \nul \left(B \right)^\perp.

Say B is n \times m, so \col B \subset \mathbb{R}^n. Then by the dimension theorem, n = \rk B + \dim \nul B. Since \rk B = \rk B^T, n = \rk B^T + \dim \nul B \implies \rk B^T = n - \dim \nul B. \tag{4}

Because \nul B is a subsapce of \mathbf{R}^n, \mathbb{R}^n = \nul B \oplus \left( \nul B\right)^\perp \implies n = \dim \nul B + \dim \left( \nul B\right)^\perp \implies \dim \left( \nul B\right)^\perp = n - \dim \nul B. \tag{5}

Combining equations [-eq-1] and 5 shows us that

\rk B^T = \dim \left( \nul B\right)^\perp. \tag{6} Becuase \rk B^T = \dim \col B^T, we have

\dim \col B^T = \dim \left( \nul B\right)^\perp, which combined with equation 3 shows that \col B^T = \nul \left(B \right)^\perp.

Combining the Steps

Applying equation 2 to our data matrix A, we have \nul A = \nul A^T A \implies \left( \nul A\right)^\perp = \left( \nul A^T A \right)^\perp . Now applying 6 from step 2 to the above yields \col A^T = \col \left( A^T A \right)^T = \col A^T A.

Conclusion

Since A^T y \in \col A^T, we know that A^T y \in \col A^T A, which tells us that there must exist an parameter vector x such that A^TA x = A^T y, and as we already demonstrated, such a solution is the minimizing solution to the MSE!

This means that the optimal set of parameters for linear regression tasks under MSE has a closed form solution.

But Why is it Called the Normal Equation?

You may be left with a question: why do we call the “normal equation”? The answer is simple. It is because Ax - y is normal to the column space of A.2 Here is the proof:

A^T A x = A^T y \implies A^T A x - A^T y = A^T \left( Ax - y \right)= \vec{0}.

For any w \in \col A, \exists z : w = Az, so \langle w, Ax-y \rangle = w^T \left( Ax - y \right) = z^T A^T \left( Ax - y \right) = w^T \vec{0} = 0. Hence, A^T x - y is normal to \col A.
